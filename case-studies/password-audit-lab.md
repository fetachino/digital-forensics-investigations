# Password-audit lab: John the Ripper

## Scope

This sanitized case study documents a controlled classroom exercise using John the Ripper to evaluate password-hash strength. It does not publish hashes, recovered passwords, wordlists, or tool binaries.

## Methodology

- Confirmed that the input was a synthetic course dataset.
- Recorded the hash format and test assumptions without reproducing secret values.
- Compared password-policy weaknesses and recovery outcomes at a summary level.
- Preserved evidence notes and separated conclusions from unsupported guesses.

## Findings and lessons

The exercise demonstrated why unique, high-entropy passwords, salted slow password hashing, and rate-limited authentication matter. The original hash file and any recovered values remain excluded from this public portfolio.
