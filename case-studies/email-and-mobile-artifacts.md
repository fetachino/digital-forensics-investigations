# Email and Mobile Artifact Analysis

## Objective

Recover and interpret communications, browser activity, application data, and location-related artifacts from controlled datasets.

## Tools

- Autopsy and ALEAPP
- Email-header and MIME inspection
- Browser and application artifact review

## Methodology

1. Preserved supplied evidence and worked from analysis copies.
2. Parsed available email metadata, message content, and attachments.
3. Enumerated browser, application, contact, download, and location artifacts.
4. Correlated timestamps while accounting for time-zone and parser limitations.
5. Recorded which conclusions were directly supported and where evidence was incomplete.

Automated parsers accelerate triage, but important findings should be validated against underlying artifacts whenever possible.
