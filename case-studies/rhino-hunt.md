# Rhino Hunt: Disk and Network Forensics

## Scenario

Investigate a controlled forensic challenge containing a disk image and multiple network traces. The work combined host artifacts with FTP and HTTP traffic to reconstruct relevant activity.

## Methodology

- Examined the disk image and recovered relevant image artifacts.
- Used Wireshark to locate file transfers in supplied network traces.
- Correlated filenames and transfer activity across disk and network evidence.
- Evaluated image content for possible steganographic indicators.
- Documented relationships between recovered artifacts and observed traffic.

## Skills demonstrated

- Cross-source evidence correlation
- FTP and HTTP protocol analysis
- File recovery and metadata review
- Introductory steganography analysis
- Reproducible forensic reporting

Challenge credentials, raw traffic, disk images, and recovered files are intentionally omitted.
