# Web-evidence lab: OWASP Broken Web Apps VM

## Scope

This case study documents a controlled web-application investigation performed against the OWASP Broken Web Apps training VM. The VM image, credentials, exploit payloads, and network captures are intentionally excluded.

## Methodology

- Used an isolated lab network and recorded the test boundary.
- Observed application behavior and collected only the evidence needed to explain each finding.
- Correlated request/response observations with server-side indicators.
- Reported impact, evidence, mitigation, and residual limitations for each issue.

## Findings and lessons

The exercise connected web-vulnerability symptoms to defensible evidence and remediation. It emphasized authorization, input validation, secure defaults, logging, and responsible disclosure within an isolated training environment.
